# SprintOAnalyzer – Downloads

Die aktuelle Version gibt es unter [Releases](https://github.com/fabian-hertner/SprintOAnalyzer-Dist/releases/latest).

- **macOS (Apple Silicon):** `.dmg` öffnen und die App in den Programme-Ordner ziehen. Beim ersten Start Rechtsklick → Öffnen.
- **Windows 10/11 (64 Bit):** `setup.exe` ausführen. Falls SmartScreen warnt: „Weitere Informationen“ → „Trotzdem ausführen“.
